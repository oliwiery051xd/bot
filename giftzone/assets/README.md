# Grafika powitalna

Opcjonalnie umieść własny plik PNG w `assets/start_banner.png`. Brak grafiki nie
blokuje działania bota: ekran powitalny zostanie wysłany jako wiadomość tekstowa.

Sugerowany format: 1280 × 640 px, tło `#0B0B12`, drugi plan `#1C1230`, akcent
`#A855F7`, tekst `#FFFFFF` i `#A1A1AA`. Napis: „🎁 MONSTAL”. Nie umieszczaj
na grafice prawdziwych kodów, adresów portfeli ani instrukcji wpłat.

Telegram sam ustala kolory przycisków i interfejsu klienta. Paleta dotyczy grafiki;
nawigacja bota korzysta z natywnych przycisków, emoji i wiadomości HTML.
